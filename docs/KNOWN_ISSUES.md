# Known issues and validation limits

- **Repeated heavy jobs:** E60 successfully executed a5s→10s→5s sequence, but other sequences failed with CUDA illegal instructions. This occurred in historical stock-state runs as well as exploratory modified-state runs. The cause is not established. E75 is one successful stock-state cold run, not proof that this is fixed.
- **Fatal GPU errors:** a normal ComfyUI queue does not rebuild a poisoned CUDA context. Stop the queue and restart the service after an illegal instruction/Xid; do not automatically retry every queued item. The external monitors used in experiments are not bundled as a production recovery feature.
- **Queue versus concurrency:** standard single-worker queueing is supported. Three lightweight control requests passed a live serial-queue check. Concurrent rendering in multiple server processes on the same two GPUs is not supported or tested.
- **Resolution/domain:** the documented planner is empirical for full INT8 H3/Kitchen50/original outputs within approximately48k tokens. Historical720p attempts failed. Do not infer720p or arbitrary-length stability from480p results.
- **Precision:** VAE FP16, local FP16 accumulation, quantization, sparse attention and distilled sampling change numerical behavior. Relative RMSE~0.42% is a local FFN observation, not an end-to-end quality limit.
- **Withdrawn options:** main `linears_fp16` produced non-finite FC2 output; FP16 runtime Larry produced audio NaNs. Do not select them as default fast modes. `ffn_fp16` has not been established as a safe full-generation substitute.
- **Staged decoder:** precision/generation must match the pipeline and decode nodes. Final-step donation was validated only for the eligible Euler/zero-final-sigma/single-condition configuration. Model/conditioning patches outside the supported runtime Larry path are rejected.
- **Reference DP:** whole-reference tasks only; one reference may not benefit. Half-precision long-video references remain gated; measured speed alone did not pass numerical validation.
- **Native dependencies:** optimized libraries and attention backends must be built separately. Missing libraries may either explicitly fail or visibly fall back, depending on the option. Node registration/API validation alone does not exercise these paths.
- **RAM preload:** tied to specific loader internals and substantial host RAM/memlock capacity. Unknown files are rejected while RAM-only mode is active. The public launcher is a packaging adaptation and still needs a complete model-run regression.
- **Editor graphs:** bundled UI files originate in historical editor examples; their H3 widgets have been aligned with the current schema and performance settings. Registration/widget schemas were checked, not every frontend interaction. API examples were validated before publication; reference placeholders require user-supplied inputs.

Report a problem with the plugin/ComfyUI/dependency commits, GPU architecture, selected settings, sanitized logs and the input's dimensions/frame count/seed. Remove access tokens, private paths, host identifiers and personal input media before sharing logs. Never attach model weights to an issue.
