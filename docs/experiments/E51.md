# E51：VAE GEMM 调优与 FP16 累加消融

2026-10-24；父实验 E50，父代码 `0702cb6ca3b58b349d734c707e76103ae5ea0bac`。三个独立实验实现分别提交：cuBLASLt、CUTLASS、FP16累加；见 commits.json。正式代码/服务/默认精度未改，退出实验进程即回退。

## 结论与峰值口径修正

保持 FP32 累加，cuBLASLt 与 CUTLASS 的 tile/Split-K 扫描未得到可晋升的稳定收益。FP16累加有明显提速，但属于精度取舍：B4完整FFN约1.38–1.42倍，局部relative RMSE约0.42%。保留显式独立进程实验开关，不设生产默认，不宣称完整VAE/视频可接受。

NVIDIA官方Turing架构表给RTX2080Ti：FP16 Tensor + FP16累加107.6/113.8 TFLOPS，FP16 Tensor + FP32累加53.8/56.9 TFLOPS（Reference/Founders Edition，1545/1635MHz Boost）。实际频率变化，所以测得超过标称56.9不矛盾；不能把FP32累加50TFLOPS直接与FP16累加114TFLOPS作利用率比较。来源：http[redacted path] 。E50经验线不是理论峰值，本轮补上该口径。

## 同精度调优

真实输入/权重来自E43的VAE block18操作数，B4每卡FC1 MNK7188/8192/2048，FC2 MNK7188/2048/4096。FP16输入/权重，FP32累加，FC1输出half带bias，FC2输出float。TF32、FP16 reduced reduction、FP16 accumulation全关。cuBLASLt的FC1使用bias epilogue；CUTLASS用bias broadcast C。所有扫描逐卡隔离，最终候选完整FFN双卡并发另测。

- cuBLASLt：每卡FC1 12、FC2 18个有效候选，共60；包含启发式tile/stage/swizzle及显式Split-K 2/4/8与可支持reduction组合。使用128MiB workspace，规划和分配不计时。每候选3预热10样本，前5名进行3轮5预热20样本与baseline配对复测。
- CUTLASS：8种CTA/warp/Ktile（64×64×32至128×256×32，包含BK64），SM75双缓冲2stage，Split-K 1/2/4/8，共128个shape/rank/config。临时workspace上限2GiB仅实验，规划/分配不计时。前3名相同配对复测。没有新增异步流水收益主张。
- 相同精度不保证逐值相同：Split-K规约顺序改变，部分候选有小误差；详细error保留。完整FFN原实现与候选均使用原版SiLU+multiply，E49融合关闭。

完整B4 FFN双卡3轮交错、各mode每轮10预热30样本，包含输出分配/API提交，不含P2P。FC2候选idx0为Lt普通，idx8/13为Split-K2，候选编号依赖当前库/shape，不能用于任意版本硬编码。

|GPU|原版 ms|Lt idx0 ms|Split-K idx8 ms|Split-K idx13 ms|
|---|---:|---:|---:|---:|
|0|7.727|7.701|7.722|7.789|
|1|7.446|7.424|7.471|7.555|

Lt idx0完整FFN仅约0.3%变化；Split-K在完整FFN没有稳定收益。CUTLASS配对复测最快仍不优于vendor。因此都不部署。

## FP16 累加独立实验

`ffn_half_e51.py --accum fp32|fp16` 必须显式指定。该开关控制实验进程的 `torch.backends.cuda.matmul.allow_fp16_accumulation`；它是进程全局flag，不适合未经隔离直接移植到Comfy并发服务。当前只在独立runner使用，不能独立控制FC1/FC2全流程消融，正式节点未暴露。`half_e51.py`单算子分别测FC1与FC2，但完整FFN比较是两者一起变化。

FP16候选FC1仍调用F.linear；FC2改为FP16累加、FP16输出，再转FP32供外部接口，因此它同时引入了FC2输出half舍入。它不是仅修改累加器的单因素FC2实验。实际没有在本轮运行P2P归约/残差/完整block。

使用B1/B3/B4（M1797/5391/7188），小批是原B4前缀，不是新视频；尺寸对应此前480p/720p VAE tile计划。模型seed/调度/视频轨迹沿历史捕获，本轮不生成新latent。20预热50正常event样本，两卡同时执行。fp32/fp16在不同进程先后测，未锁频；加速比是本轮测量，不当硬性保证。

孤立FC1 relative RMSE约0.175–0.178%，FC2约0.312–0.315%；完整FFN约0.418–0.432%。此误差是该层局部张量差异，不是画质损失百分比。全部实测输出有限；未覆盖极端输入溢出/所有层/完整VAE/成片，不晋升默认。
