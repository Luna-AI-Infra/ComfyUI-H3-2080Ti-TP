# E65 多参考 VAE 编码双卡 DP

已实现独立节点 **H3ReferenceToVideoDP**（UI：H3 Reference to Video (DP encoders)），原节点保留。

正式服务以 `--fp32-vae` 运行，参考视觉/音频编码为FP32；视觉解码由另一节点选择TP2 FP16。这两个精度设置不可混淆。当前FP32多图、多视频、多音频可按完整参考素材分配GPU0/1；单份素材回退单卡。不新增视频切段，不拆单段音频的声道，不改变素材标签和结果顺序。

## 配置与边界

| 参数 | 默认 | 行为 |
|---|---|---|
| encode_mode | auto | 多份参考、两卡可用且显存预检满足时DP，否则先回退single；dp2为强制模式，条件不满足时报错 |
| allow_unvalidated_video | false | 非FP32视频编码默认不进DP；true仅供低精度视频消融，有已知数值偏差风险。FP32视频不需要打开 |
| 编码精度 | 继承VAE | 当前服务FP32；不新增量化或低精度累加 |

每卡复制所需编码器，不复制视觉Transformer解码器或音频BigVGAN解码器。模型参数直接复制到最终GPU分配，避免额外CPU深拷贝。全局Comfy卸载在调用线程执行，之后两线程/两CUDA stream分别编码。按索引汇合结果、释放副本，再执行Qwen TP。当前没有Qwen与VAE并发，也没有新增持久GPU编码器缓存。

显存预检为各卡编码器参数+最大作业原VAE激活估算+2GiB安全量，不是峰值保证。DP worker真实OOM直接抛出；single沿用原Comfy编码行为，可能内部重试tiling，实验监控遇到OOM则停止矩阵。作业按元素数粗略均衡，跨图像/音频的成本尚未校准。
