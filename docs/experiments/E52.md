# E52：组合候选端到端验证

2026-10-24。有效热测 **115.734 → 110.617s，1.046×，耗时减少4.42%**。每种配置各一次正常热测，未锁频，不能当作稳定统计均值。新组合完整生成成功，但未晋升生产默认。

初始全部开启的组合失败：主干内部FP16输出在block index18（第19层）FC2首先出现非有限值，后续video/audio latent全部异常。最终有效组合恢复主干内部输出original，保留其余候选。失败配置8.2s/step不得作为有效加速结果。

## 失败与冷预热

初始combined/cold_warmup：采样/VAE执行后在AAC avcodec_send_frame返回EINVAL，未成功保存。diagnostic2显示video latent1438560/audio latent13248元素全部非有限，音频波形331200元素全部非有限；错误早于VAE。diagnostic3逐线性层同步检查：block18 rank0 FC2，输入[4096,28672]有限、absmax82.375，输出[4096,2688]中2个非有限。这是观察证据；尚未将异常细分到INT8 epilogue舍入与LoRA最终half转换，不能凭此证明具体哪个内部中间值溢出。仅撤回内部输出开关后完整视频成功。

第一次diagnostic启动因实验launcher过早import execution使CLI未解析，temp落系统盘ENOSPC，未推理；修正enable_args_parsing后诊断成功。全部日志保留。

基线cold_warmup1237.465s受NAS冷读影响，中途四线程只读预取34,038,892,334bytes，持续500.991s，与装载重叠；预取结束前暂挂父调度器，结束后恢复，保证后续热测没有该I/O。该次不是干净冷启动基准，不和后续OS缓存已热的冷进程耗时计算加速比。safe_combo冷进程预热259.705s；两者不可直接比较。
