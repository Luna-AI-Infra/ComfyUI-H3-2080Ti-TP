# E61 Ref2VA 优化复用扫描结果

结论：现有组合能完成Ref2VA单图冷/热和双图冷生成，但出现两次CUDA illegal instruction，尚不能标为稳定复用；10s被保护流程阻止，未执行。未调整或推广生产精度默认值。

## 失败及未完成

首批single-flash：auto预算仅支持Kitchen，故显式manual3/2，实际与single-hot相同组/槽；单步13.8–14.0s只作部分观察，约第4步后报CUDA illegal instruction。不能计算严格完整加速比。原进程终止后保留全部日志。
独立进程double-cold成功，double-hot在首步报同类错误，说明不应仅归因Flash后端。异常在tp_comm.close的stream.synchronize处暴露，异步栈不能定位产生错误的kernel。内核日志GPU1（PCI82:00）Xid13含Out Of Range Register/Multiple Warp Errors及Xid43，根因尚未定位；不是已证实硬件损坏。
按照保护规则停止矩阵，single-10s未执行，没有自动换精度/降分辨率重试。同样没有为了完成矩阵绕过错误。下一步应先用真实Ref block输入在干净进程隔离通信/FC2/低精度/attention，复现定位后再扩容。
